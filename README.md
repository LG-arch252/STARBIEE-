# STARBIEE!!

A compact, star-shaped environmental sensing project powered by the ESP32-C3.

Starbie is a custom electronics project that combines environmental sensing, motion sensing, and a display interface on a uniquely designed star-shaped PCB. Built around the ESP32-C3, it brings together multiple sensors and physical controls in a compact board.

Features: -

- Custom star-shaped PCB design
- ESP32-C3 microcontroller
- DHT11 sensor for temperature and humidity
- OLED display interface
- MPU6050 accelerometer and gyroscope for motion and orientation data
- Two physical push buttons for user input
- Dedicated connectors for sensors and peripherals
- 3.3V-compatible sensor interfaces

 How It Works: -

The ESP32-C3 acts as the central controller, communicating with the connected sensors and peripherals. The DHT11 provides temperature and humidity readings, while the MPU6050 supplies motion-related measurements. The OLED interface is intended to display information processed by the microcontroller, and the two push buttons provide a way to interact with the device. The components are connected through dedicated PCB footprints and connectors, making the design compact and organized..
